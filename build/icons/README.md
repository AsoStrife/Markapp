# Icons

Posiziona qui le icone per l'applicazione Electron:

- **icon.png**: Icona principale (almeno 512x512 px)
- **icon.ico**: Icona per Windows (256x256 px)
- **icon.icns**: Icona per macOS (512x512 px)

## Generazione automatica

Electron-builder può generare automaticamente le icone per tutte le piattaforme partendo da un file PNG di almeno 1024x1024 px.

Rinomina la tua icona in `icon.png` e posizionala in questa cartella.
