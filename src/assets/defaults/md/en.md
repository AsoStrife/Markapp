# Welcome to Markapp!

This is a modern **Markdown editor** inspired by Typora.

## Features

- Split view editor
- Raw Markdown on the left
- Rendered preview on the right
- Save and open .md files

## Code example

```javascript
function greet(name) {
    return `Hello, ${name}!`
}

console.log(greet('World'))
```
