# Benvenuto in Markapp!

Questo è un **editor Markdown** moderno in stile Typora.

## Caratteristiche

- Editor con split view
- Markdown grezzo a sinistra
- Preview renderizzata a destra
- Salva e apri file .md

## Esempio di codice

```javascript
function saluta(nome) {
    return `Ciao, ${nome}!`
}

console.log(saluta('Mondo'))
```
